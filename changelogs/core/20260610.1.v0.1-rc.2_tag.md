# CHANGELOG — 20260610.1.v0.1-rc.2_tag.md

## Summary

This release focuses on finalizing external consumption of the Core from real-world projects and completes the runtime execution pipeline with dedicated action lifecycle hooks.

The main objective of this release is to support WSC integration and validate Core usability as a standalone framework for building production CLI applications.

---

## Added

### Runtime Action Hooks

Added two new runtime hooks:

* `beforeAction`
* `afterAction`

These hooks execute respectively:

```text
BeforeAction
↓
Action
↓
AfterAction
```

and provide a runtime-level interception point immediately before and after userland execution.

The hooks receive:

* runtime
* tools
* snapshot
* live events

and intentionally do not expose:

* action options
* action arguments

to remain action-agnostic and focused on runtime orchestration concerns.

### Core Pipeline Completion

The execution pipeline now exposes all major extension points:

```text
BuiltinStageDefaults
↓
BuiltinStage
↓
BuiltinGlobals
↓
ModuleResolution
↓
BeforeAction
↓
Action
↓
AfterAction
```

This completes the initial runtime hook architecture planned for v0.1.

---

## Fixed

### Public Type Exports

Resolved missing public type exports required for external consumption of `CLI.init()`.

Several runtime enums and configuration types were correctly generated in declaration files but were not exposed through the public package API.

The following types are now exported through the package entrypoint:

* `CoreEventKind`
* `CoreEventLevel`
* `CoreEventPhase`
* `GlobalOption`
* `Option`

This fixes external TypeScript projects consuming Core through packaged releases.

### Public Export Structure

Introduced a dedicated public export layer (`publicTypes`) to explicitly manage public type exposure without modifying the auto-generated internal export system.

This preserves the separation between:

* internal implementation exports
* supported public API exports

and establishes a clean foundation for future public type management.
