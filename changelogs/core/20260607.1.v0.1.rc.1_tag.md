# v0.1.0-rc.1

Date: 2026-06-07

## Overview

This Release Candidate establishes the first stable foundation of the Core Runtime.

The primary goal of this milestone is to freeze the runtime architecture, parser behavior, event system, help system and development conventions before integrating Core into WSC.

This release is not intended to be feature complete. Its purpose is to provide a stable and validated baseline for future KamieLabs projects.
